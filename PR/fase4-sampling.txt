VERIFIKASI POSISI NAIP (preview vs COG bergeoreferensi, 770 m)
- Arcata: 5 titik -> best shift (0,0); korelasi 0.85-0.96.
- Tyee City, Arcata, McKinleyville, Trinidad, Blue Lake: 1 titik/kota -> best shift (0,0).
- Sebelum perbaikan: preview bergeser ~8 px (~48 m) karena dipetakan linear pada lon/lat.

SKALA CROSSHAIR (luas ground disamakan)
- SAR      : 128 px * 0.5 arcsec ~ 1.49 km lebar -> skala 1.00
- Sentinel : 128 px * 10 m = 1.28 km lebar -> skala 1.49/1.28 = 1.17
- NAIP     : 128 px * 770 m = 0.77 km lebar -> skala 1.49/0.77 = 1.94
- Crosshair simetris; lebar ground yang ditunjuk sama untuk ketiga sumber.
- SAR pixel ground sedikit lebih tinggi (15.4 m vs 11.7 m), sehingga lengan vertikal
  crosshair SAR mencakup ground ~24% lebih panjang; skala di atas menyamakan arah horizontal.

CARA PAKAI
1. Buka output/L1/<kota>/labeling/labeling.html di browser.
   Jika localStorage/img bermasalah via file://, jalankan server lokal:
     python -m http.server -d output/L1/<kota> 8000
   lalu buka http://localhost:8000/labeling/labeling.html
2. Tekan 1=berubah, 0=tidak, u=ragu, s=lewati, backspace/<-=kembali.
3. Spasi = tampilkan/sembunyikan crosshair.
4. Klik Export CSV -> labels_<slug>.csv.
5. Gabungkan: python src/combine_labels.py <file1.csv> ... --out labels/L1_labels.csv
